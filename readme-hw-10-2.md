# Домашнє завдання 10-2

Обчислити інтеграл функції f(x) = x² на проміжку [0, 2] методом Монте-Карло.
Порівняти з аналітичним розв'язком та з функцією `scipy.integrate.quad`.

## Аналітичне обчислення

∫(0..2) x² dx = [x³/3] від 0 до 2 = 8/3 ≈ 2.666667

## Метод Монте-Карло

Беремо N випадкових точок на [a, b] і обчислюємо середнє значення функції
у цих точках. Інтеграл наближено дорівнює `(b - a) * середнє`.

## Результати вимірювань

| Метод | Результат | Різниця з аналітичним |
|---|---:|---:|
| Аналітично          | 2.666667 | 0 |
| scipy.quad          | 2.666667 | 2.96e-14 |
| Монте-Карло (N=1000)    | 2.572043 | 0.094623 |
| Монте-Карло (N=10000)   | 2.664608 | 0.002059 |
| Монте-Карло (N=100000)  | 2.680659 | 0.013992 |
| Монте-Карло (N=1000000) | 2.665053 | 0.001614 |

## Висновки

- Метод Монте-Карло дає наближене значення інтеграла. Чим більше точок N,
  тим менша похибка — на 1000 точок різниця близько 0.09, а на 1 000 000
  вже 0.0016.

- Похибка зменшується пропорційно 1/√N — щоб зменшити похибку у 10 разів,
  потрібно у 100 разів більше точок. Тому N=100000 не обов'язково
  точніший за N=10000 (видно на результатах вище).

- Функція `scipy.quad` повертає майже точне значення з похибкою близько
  10⁻¹⁴, що практично збігається з аналітичним розрахунком.

- Для простих функцій типу x² метод Монте-Карло поступається `quad` —
  він повільніший і менш точний. Але для складних багатовимірних функцій,
  де аналітичний розв'язок неможливий, Монте-Карло — один із небагатьох
  доступних методів.
